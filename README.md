# 서울시 생활 편의지수 분석

서울시 25개 자치구를 대상으로 인구 구조, 생활 편의 시설 분포, 지하철 접근성을 비교해 지역별 생활 편의 수준을 분석한 프로젝트입니다. 병원, 약국, 음식점, 상비약 판매업소 데이터를 자치구 단위로 집계하고, 인구 1,000명당 시설 수와 교통 접근성 지표를 활용해 생활 편의지수를 산출했습니다.

## 1. 프로젝트 개요

### 목적

- 서울시 자치구별 생활 편의 시설 분포를 정량적으로 비교
- 인구 구조와 시설 공급 수준 사이의 관계 확인
- 교통 접근성과 시설 밀집도 사이의 상관관계 분석
- 생활 편의지수를 통해 자치구별 편의 수준과 지역 간 격차 파악

### 분석 대상

- 공간 범위: 서울특별시 25개 자치구
- 분석 단위: 자치구
- 주요 시설: 병원, 약국, 일반음식점, 상비약 판매업소
- 추가 지표: 인구 구조, 시가화면적, 지하철역 수

## 3. 분석 방법

### 데이터 전처리

1. 자치구명을 기준으로 각 시설 데이터를 집계
2. 인구 데이터에서 총인구, 고령화율, 청년비율, 성비 계산
3. 시가화면적과 지하철역 수를 결합해 교통지수 생성
4. 모든 데이터를 자치구 단위의 하나의 분석 테이블로 병합

### 주요 지표

| 지표 | 계산 방식 | 의미 |
| --- | --- | --- |
| 인구 1,000명당 시설 수 | `시설 수 / 총인구 * 1000` | 인구 규모를 보정한 시설 공급 수준 |
| 인구밀도 | `총인구 / 시가화면적` | 실제 생활 공간 기준 인구 밀집도 |
| 교통지수 | `지하철역 수 / 시가화면적` | 시가화면적 대비 지하철 접근성 |
| 변동계수(CV) | `표준편차 / 평균` | 자치구 간 시설 분포 격차 |
| 생활 편의지수 | 표준화된 시설 및 교통 지표 결합 | 자치구별 종합 편의 수준 |

### 통계 분석

- Pearson 상관분석: 변수 간 선형 관계 확인
- Spearman 상관분석: 순위 기반 관계 확인
- 변동계수 분석: 시설 유형별 지역 간 불균형 비교
- 시각화: 막대그래프, 히트맵, Folium 기반 단계구분도

## 4. 주요 결과

- 시설 간 상관관계가 높게 나타나 특정 자치구에 여러 편의 시설이 함께 집중되는 경향이 확인되었습니다.
- 시설 유형 중 일반음식점의 변동계수가 높아 자치구 간 격차가 크게 나타났습니다.
- Pearson 분석에서는 인구 구조와 시설 공급 수준 사이의 유의한 관계가 뚜렷하지 않았습니다.
- Spearman 분석에서는 청년비율과 음식점, 상비약 판매업소 사이에서 일부 순위 기반 관계가 확인되었습니다.
- 교통지수는 음식점 및 약국 밀도와 유의한 양의 상관관계를 보여, 교통 접근성이 시설 밀집과 관련이 있음을 확인했습니다.
- 생활 편의지수는 중구, 종로구, 강남구 등 중심 지역에서 높게 나타났고, 도봉구, 양천구, 노원구 등 일부 지역은 상대적으로 낮게 나타났습니다.

## 5. 결론

서울시의 생활 편의 수준은 단순한 인구 규모나 연령 구조보다 시설 공급 수준과 지하철 접근성에 더 크게 영향을 받는 것으로 나타났습니다. 특히 중심 업무 및 상업 지역은 교통 접근성과 편의 시설 밀집도가 함께 높게 나타났으며, 일부 외곽 지역은 상대적으로 낮은 편의지수를 보였습니다.

따라서 지역 간 생활 편의 격차를 줄이기 위해서는 편의지수가 낮은 자치구를 중심으로 시설 확충 우선순위를 검토하고, 교통 접근성과 실제 이용 수요를 함께 고려한 정책 설계가 필요합니다.
